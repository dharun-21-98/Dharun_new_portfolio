# Micro-interactions

Buttons should have subtle hover animations.

Cards should slightly elevate on hover.

Project cards should display technology tags on hover.

Timeline items should animate into view while scrolling.

Numbers should animate from zero when entering the viewport.

Navigation should highlight the active section while scrolling.

Scrolling should feel smooth and responsive.

---

# Mobile Experience

Navigation collapses into a hamburger menu.

Project cards become swipeable.

Statistics become a two-column grid.

Timeline becomes vertical.

Buttons remain full width.

Typography scales appropriately without sacrificing readability.

---

# Accessibility

Maintain sufficient color contrast.

Ensure all interactive elements are keyboard accessible.

Provide descriptive alt text for images.

Use semantic HTML structure throughout.

Respect users' reduced motion preferences by minimizing animations when enabled.

---

# Final Impression

A recruiter should be able to understand who I am, what I've built, and how I think within one minute of landing on the homepage.

The homepage should encourage deeper exploration of the project case studies while making it effortless to download my resume or get in touch.
